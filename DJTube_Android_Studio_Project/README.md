# DJTube Android App Project
Música y Video Player con Descargas de Alta Calidad (FLAC, WAV, MP3 320k, AAC, 1080p).

## Requisitos
- Android Studio Ladybug o superior
- SDK Android 35 (Android 10+ mínimo SDK 29)
- JDK 17

## Arquitectura
- Kotlin 2.0+ & Jetpack Compose (Material Design 3)
- ViewModel MVVM + Coroutines StateFlow
- Room Database para almacenamiento local
- Media3 / ExoPlayer para reproducción fluida de audio y video
